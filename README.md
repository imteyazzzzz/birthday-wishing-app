# 🎂 Interactive Birthday Wishing Web App 🎉

A vibrant, mobile-first, feature-packed Birthday Celebration web application crafted for best friends. Built using pure **HTML5**, **CSS3**, and **Vanilla JavaScript** with zero build tools or dependencies needed.

---

## ✨ Key Features

- **🎈 Balloon Popping Mini-Game:** Tap/click floating balloons to pop them with realistic sound effects, confetti bursts, and unlock hilarious friendship roasts & birthday blessings.
- **🎂 Virtual Cake Cutting & Candle Blowing:** Interactive candle extinguishing with smoke effects, followed by dynamic knife swipe to slice the cake with fanfare.
- **📸 Polaroid Memories Carousel:** Touch-friendly swipeable Polaroid photo gallery with realistic tape pins and handwritten notes (`Caveat` font).
- **🎁 Secret Gift Box:** Interactive 3D gift box with popping lid and unfolded customizable birthday letter.
- **🎵 Built-in Synthesizer & Audio Player:** Plays upbeat celebratory birthday tunes directly via Web Audio API, or supports custom MP3 upload.
- **⚙️ Live Customizer / No-Code Studio:** Live edit modal to customize:
  - Birthday person's Name, Nickname & Age
  - Tagline & Gang titles
  - Custom Wish Note & Signature
  - Photos & Custom BGM
  - Shareable link generator with URL parameter state encoding.

---

## 🚀 Live Demo / Quick Start

Simply clone the repository and open `index.html` in any browser, or run a local server:

```bash
# Clone the repository
git clone https://github.com/imteyazzzzz/birthday-wishing-app.git

# Navigate into directory
cd birthday-wishing-app

# Open in browser or run local server
python -m http.server 8080
```

Then visit `http://localhost:8080` or open `index.html` directly.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure, viewport optimization.
